# Pokémon Project

This is a fun project that lets you explore Pokémon data using an API. You can search for your favorite Pokémon, view their stats, abilities, moves, and even see their evolution chain.

## Features
- Search for any Pokémon
- View Pokémon stats, abilities, and moves
- Toggle dark mode
- Add Pokémon to your favorites
- Play sound effects
- View Pokémon evolution chain

## Installation
1. Clone the repository:  
   `git clone https://github.com/rahulranjan1624/pokemon_project.git`

2. Navigate to the project folder:  
   `cd pokemon_project`

3. Install the dependencies:  
   `pip install -r requirements.txt`

4. Run the Flask server:  
   `python app.py`

## Usage
1. Open the project in your browser.
2. Search for any Pokémon by name or ID.
3. Explore the details and enjoy the features!
